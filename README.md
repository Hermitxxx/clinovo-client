## 🩺 What is Clinovo?

**Clinovo** is a modern, full-stack healthcare consultation platform that bridges the gap between patients and certified medical specialists — anytime, anywhere.

No waiting rooms. No scheduling headaches. Just instant access to top-rated doctors via **video visits** or **real-time chat**, available **24 hours a day, 7 days a week**.

> *"Your health, our priority."*

## 🚀 Getting Started

### Prerequisites

- Node.js `v18+`
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/clinovo.git
cd clinovo

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
# Fill in your values in .env.local

# 4. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. 🎉

## 🌍 Deployment

Clinovo is deployed on **[Vercel](https://vercel.com)** with zero-config CI/CD.

Every push to `main` triggers an automatic production deployment.

```bash
# Deploy manually via Vercel CLI
npx vercel --prod
```
